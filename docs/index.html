Features

Pro Wave does a lot, and aims to do it the way Logic Pro does: arranging, recording, editing, mixing and bouncing in one window, on an engine where the audio thread never waits.

Engine

Real-time and lock-free

Sample-accurate transport, cycle, count-in and a tempo and signature map. No allocation, locks or disk access on the audio thread; 64-bit summing and plug-in delay compensation.

Arrange

Tracks and regions

Audio, Instrument, Drummer, Pattern, Aux, VCA, Folder and External MIDI tracks. Cut, copy, paste, split, join, Paste Replace, Bounce in Place and Bounce and Join, with a jumpable undo history.

Record

MIDI and audio

Count-in, cycle and takes. Follow or send MIDI clock and MIDI Time Code; MIDI out with program, bank, pitch bend and SysEx.

Edit

Piano Roll, Score and more

Quantize with strength and swing, scale quantize, velocity lane, Event List, Step Sequencer, MIDI Transform, and a Score view with MusicXML export.

Mix

Mixer and automation

Channel strips with sends, buses, groups and VCA. Automation for faders, pan, sends and every effect parameter in Read, Touch, Latch and Write.

Effects

Real DSP

Channel EQ, Multi-Band EQ, Compressor, Multi-Band Compressor, Noise Gate, Limiter, Space Designer convolution reverb, Tape Delay, Chorus, Phaser, Overdrive, Filter and Amp Designer. On any strip, even the Stereo Out.

Sound

Instruments

A 48-voice subtractive synth with drum-kit modes, SoundFont (.sf2) instruments, Hydrogen drum kits and Library patches.

Flex

Flex Time, Flex Pitch, Smart Tempo

Warp and re-pitch audio, detect tempo, and make a project follow a recording.

Audio

Non-destructive regions

WAV, AIFF, FLAC, MP3, CAF, OGG and M4A streamed from disk. Gain, fades, crossfades, reverse and normalize never touch the file.

Share

Bounce and export

Bounce the project or a cycle section to a 32-bit WAV, export one track, or write the selection as a MIDI file.

Import

Open formats

.prowave projects, MIDI files (SMPTE time and markers too), audio files and the audio of GarageBand projects.

Everywhere

Linux, macOS, Windows

.deb, .rpm, AppImage, Flatpak, a macOS app and a Windows zip. A program of about 15 MB that starts in a few hundred milliseconds.

See it

The look and workflow follow Logic Pro: dark panels, Library, Inspector, Tracks area and Mixer.

Piano Roll with quantize and velocity lane

Playback with live channel meters

Light and real-time

The audio thread never locks, allocates or touches the disk. The UI talks to the engine only through a lock-free command queue.

~15 MB program

Starts in a few hundred milliseconds and idles around 120 MB of memory.

Sample-accurate

Transport, tempo map and automation run on the audio clock, with plug-in delay compensation.

64-bit summing

Tracks are summed in double precision before the master fader.

Honest status

Pro Wave is alpha software. Plug-in hosting, Live Loops and much of Logic's instrument list are still to come. Every release lists what was tested and what was not.

DOWNLOAD

Get Pro Wave.

Prebuilt packages for every system. Free and open source under the GPL.

Linux

An AppImage needs no installation. Also .deb, .rpm, a Flatpak bundle and a tar.gz with an installer.

Linux x86-64Install steps
$ chmod +x ProWave-*.AppImage
$ ./ProWave-*.AppImage

macOS

A universal app for Apple Silicon and Intel. It is ad-hoc signed, not notarized: clear the quarantine before the first launch.

macOS (.zip)
$ xattr -dr com.apple.quarantine \
  "/Applications/Pro Wave.app"

Windows

Windows 10 and 11, x86-64. Unzip and run prowave.exe. SmartScreen warns because the file is not code signed.

Windows (.zip)

From source

Rust stable, plus ALSA development files on Linux. The README has the packages for every distribution.

Build instructions →
$ cargo run --release -p prowave-app
⚠ Pro Wave is alpha software and is considered unstable, especially the project file format. Keep your projects backed up and use it at your own risk.
